# Clean workstation restore checklist

1. Install Git and clone the three repositories separately into `D:\AR-Home-Exhibition\ArtTechBackend`, `D:\AR-Home-Exhibition\ArtTechArtistPanel`, and `D:\AR-Home-Exhibition\ARWallArtPrototype`. Copy the backed-up root `AGENTS.md` and `docs/` from `ArtTechBackend/docs/workspace-checkpoint/root-workspace/` to the workspace root.
2. Install the .NET 10 SDK, PostgreSQL (including a local admin/test user), Node.js/npm if browser tests are used, and Unity `6000.3.9f1` with Android Build Support, Android SDK & NDK Tools, and OpenJDK.
3. Backend: copy `ArtTechGallery.API/appsettings.Development.example.json` to the ignored `appsettings.Development.json`; replace only local placeholders for PostgreSQL, CORS origins, `ArtworkStorage:RootPath`, and `ArtworkStorage:PublicBaseUrl`. Never commit this file. Start PostgreSQL and run the backend with `dotnet run --project ArtTechGallery.API`.
4. Panel: use the committed appsettings examples and set the local API origin as needed for the static app. Run `dotnet restore`, `dotnet build`, and the maintained tests; use the existing browser test scripts with the local backend.
5. Unity: open `ARWallArtPrototype` in Unity 6000.3.9f1. Recreate ignored `Assets/Resources/ViewerLocal.json` with placeholders such as `{ "apiBaseUrl": "http://<LAN-IP>:<API-PORT>", "shareBaseUrl": "http://<LAN-IP>:<PANEL-PORT>" }`. For a phone, bind the backend to a reachable LAN interface, set CORS and managed-image public origin to the same reachable API origin, allow the ports through Windows Firewall, and use the computer’s current LAN IP—not a committed value.
6. Run the maintained backend PostgreSQL tests, panel tests/browser smoke, and Unity EditMode/PlayMode tests. The opt-in real-backend tests require disposable local configuration and must not receive committed credentials.
7. Build an Android APK from Unity only after the clean machine has a healthy Gradle/SDK setup. Then perform the exact first milestone: **PHYSICAL ANDROID MVP SMOKE TEST** — cold start custom-scheme profile and exhibition links, web fallback, ProfileCode/ExhibitionCode navigation, published-only visibility, artwork image loading, Android Back, and Quick Mode physical scale.

Keep ignored local config, runtime uploads, generated build/cache folders, tokens, passwords, and LAN addresses out of Git. Use placeholders wherever a local value is required.
